# 示意图：在回答里直接画

对话界面会把回答里的 ```mermaid 代码块直接画成图（能放大、能看原文），不用生成图片文件。

## 怎么写

- 在回答正文里写一个 ```mermaid 代码块，前后用一两句话说这张图讲什么、怎么看。
- 按内容选图：
  - 步骤、分支、审批流转：`flowchart`（从上到下 `flowchart TD`，从左到右 `flowchart LR`）；
  - 谁和谁按先后交互（系统调用、来回沟通）：`sequenceDiagram`；
  - 层级、组织、模块构成：`flowchart TD` 画成树；
  - 排期、阶段：`gantt`；
  - 要点发散、梳理思路：`mindmap`；
  - 状态怎么变（单据、工单的状态）：`stateDiagram-v2`。
- 节点文字里有括号、标点或空格时用双引号括起来，例如 `A["提交申请（附发票）"]`；子图标题同样。
- 一张图别太大：节点超过二十个左右就分层或拆成几张。
- 写完对一遍语法：箭头、引号、括号成对，`gantt` 的日期格式和 `dateFormat` 一致。

## 不用它的时候

- 带数的图（趋势、对比、占比、分布）：有 show_chart 就用它展示；不要拿 mermaid 的 xychart、pie 画数。
- 用户明确要图片文件，或要把图放进 Word、PPT、PDF：照常生成文件，按对应的 Office 技能交付。
